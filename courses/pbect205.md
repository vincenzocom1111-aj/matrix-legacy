## Module 1: Introduction to PLCs

A **Programmable Logic Controller (PLC)** is an industrial digital computer
used to automate electromechanical processes.

[IMG: plc_block_diagram(basic PLC block diagram showing CPU, input and output modules)]

- Rugged, designed for harsh industrial environments
- Real-time control with deterministic scan cycles

### Q&A
Q: What does PLC stand for?
A: Programmable Logic Controller.

Q: Name one advantage of PLCs over relay-based systems.
A: Easier to reprogram without rewiring, and more reliable in harsh
   industrial environments.

## Module 2: Ladder Logic Basics

Ladder logic is the most common PLC programming language, modeled after
relay logic diagrams.

$$Output = InputA \\cdot InputB$$

### Q&A
Q: What is ladder logic modeled after?
A: Relay logic diagrams used in electromechanical control panels.
